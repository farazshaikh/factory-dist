curl -fsSL --proto '=https' --tlsv1.2 https://farazshaikh.github.io/factory-dist/install.sh | bash

The command becomes available when the public release and this site are published. Inspect the installer before running it. Downloads are verified against release SHA-256 checksums; no sudo is used.

Start a project
export PATH="$HOME/.local/bin:$PATH"
cd /path/to/your/project
factory init --name "My Project"
factory serve web

Research / planning / execution

Closed source. Open specifications.

Factory's implementation stays private. Its interface and storage specifications are the integration surface: inspect the contracts, understand your data, and connect your tools.

  • HTTP API / OpenAPI
  • Domain types / JSON Schema
  • Repository layout
  • Record envelope / Protobuf
  • Domain records / Protobuf
  • Persistence constraints

Specification licensing and binary distribution terms are pending owner approval. Availability of a specification does not grant a license to Factory's implementation.
